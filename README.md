# Telegram Subscription Bot

Бот продаёт доступ к закрытому Telegram-каналу и ведёт учёт подписок в SQLite. Поддерживает Telegram Stars и опциональную интеграцию Crypto Pay API, ручное продление, напоминания за сутки, автоматическое исключение после окончания подписки, реферальные бонусы и админ-панель.

Telegram требует использовать Stars для продажи цифрового доступа внутри приложения. Для такого запуска оставьте `CRYPTOBOT_TOKEN` пустым. Интеграцию Crypto Pay можно проверять в тестовой сети. [Правила Telegram для цифровых товаров](https://core.telegram.org/bots/payments-stars) · [Документация Crypto Pay API](https://help.send.tg/en/articles/10279948-crypto-pay-api)

## Настройка

1. Отправьте команду `/newbot` в @BotFather, задайте имя и username. Сохраните токен для `BOT_TOKEN`. [@BotFather](https://t.me/BotFather)
2. Создайте закрытый канал и добавьте бота его администратором. Дайте боту права приглашать пользователей и блокировать участников. Чтобы принимать заявки на вступление, создайте отдельную ссылку с одобрением администратора. Закройте старые ссылки со свободным входом, чтобы доступ проходил через проверку подписки.
3. Скопируйте `.env.example` в `.env` в корне проекта. В Bot API возьмите `CHANNEL_ID` из `channel_post.chat.id` обновления о публикации в канале, а ID для `ADMIN_IDS` из `message.from.id` обновления о личном сообщении каждого администратора боту.
4. Запустите бота. Каждый администратор должен открыть с ним личный чат и отправить `/start`, чтобы получать уведомления.

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_IDS` | Один или несколько положительных числовых ID администраторов через запятую, например `123456789,987654321` |
| `CHANNEL_ID` | Отрицательный числовой ID канала, например `-1001234567890` |
| `CRYPTOBOT_TOKEN` | Токен приложения Crypto Pay. Пустое значение скрывает оплату USDT |
| `CRYPTOBOT_TESTNET` | `true` для тестового приложения из [@CryptoTestnetBot](https://t.me/CryptoTestnetBot), `false` для основной сети [@CryptoBot](https://t.me/CryptoBot). По умолчанию `false` |
| `REFERRAL_PERCENT` | Процент бонуса с платежей приглашённых от 0 до 100, по умолчанию `15` |
| `DB_PATH` | Путь к файлу SQLite, по умолчанию `bot.db`. Относительный путь считается от рабочего каталога. Для вложенного пути заранее создайте папку |

Переменные окружения процесса имеют приоритет над значениями из `.env`.

Нужен Python 3.11 или новее. Из корня проекта выполните:

```text
python -m venv .venv
```

Активируйте окружение командой `source .venv/bin/activate` в Bash или `.\.venv\Scripts\Activate.ps1` в PowerShell. В Windows также можно запускать Python из окружения напрямую: `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` и `.\.venv\Scripts\python.exe main.py`.

```text
pip install -r requirements.txt
python main.py
```

Запускайте один экземпляр бота для одного токена и файла БД. В базе хранятся платежи, сроки доступа, бонусы и временные ссылки. Храните `.env` и резервные копии БД отдельно от публичного репозитория. Для переключения сети Crypto Pay используйте отдельный `DB_PATH`, поскольку номера счетов относятся к конкретной сети.

## Тарифы и доступ

| Срок | Stars | USDT |
| --- | ---: | ---: |
| 7 дней | 50 | 1.50 |
| 30 дней | 150 | 4.00 |
| 90 дней | 400 | 10.00 |
| Навсегда | 1000 | 25.00 |

Отправьте `/start` в личном чате с ботом и выберите **Тарифы**. Тарифы хранятся в `TARIFFS` в файле `bot/config.py`. В **Профиле** виден статус подписки и срок в UTC для активной срочной подписки.

- **Stars.** Бот выставляет счёт в XTR, проверяет покупателя, сумму, валюту и подпись счёта перед оплатой и зачисляет платёж после подтверждения Telegram.
- **CryptoBot.** Счёт USDT создаётся через `createInvoice` на один час. После оплаты нажмите **Проверить оплату** под счётом. Бот проверяет через `getInvoices` статус, сумму и валюту счёта, привязанного к вашему аккаунту. В разделе **Мои счета CryptoBot** можно повторно проверить до 10 последних счетов, которые ещё не зачислены в БД. Раздел доступен при настроенном `CRYPTOBOT_TOKEN`.
- **Продление.** Дни прибавляются к дате окончания активной срочной подписки. При отсутствии активной подписки отсчёт начинается в момент зачисления. Повторное подтверждение того же платежа обрабатывается без повторного начисления дней и бонусов. Бессрочный доступ сохраняется при покупке срочного тарифа. Автоматического списания нет.
- **Вступление.** После зачисления бот отправляет ссылку с лимитом в одного участника. Она действует до 15 минут или до окончания подписки, если та закончится раньше. При обработке события входа бот отзывает ссылку и проверяет подписку вступившего. Активный подписчик может запросить новую ссылку кнопкой **Получить ссылку в канал** в профиле. Заявки в настроенный канал бот одобряет при активной подписке. При отказе он пытается отправить пользователю предложение оформить доступ.

## Реферальная программа и поддержка

Раздел **Реферальная программа** показывает личную ссылку, число приглашённых и бонусные балансы. Команда `/start ref_<id>` привязывает уже зарегистрированного реферера при первой регистрации приглашённого. Самоприглашение исключено. Бонус начисляется с зачисленных платежей приглашённого в валюте оплаты. Балансы XTR и USDT учитываются отдельно.

Кнопка **Подать заявку на вывод** при положительном балансе отправляет администраторам данные пользователя и суммы. Перечисление средств и учёт выплаченных бонусов ведутся вручную. Команда `/paysupport <описание проблемы>` пересылает описание и ID пользователя администраторам.

## Администрирование

- `/admin` открывает панель в личном чате для пользователей из `ADMIN_IDS`. Статистика показывает число зарегистрированных пользователей, активные подписки и валовую сумму зачисленных платежей отдельно в Stars и USDT.
- Нажмите **Выдать / продлить** и введите ID пользователя и срок от 1 до 36500 дней, например `123456789 30`. Для бессрочного доступа введите `123456789 forever`. Пользователь должен быть зарегистрирован в БД.
- Нажмите **Забрать** и введите ID пользователя. Чтобы разослать сообщение, нажмите **Рассылка** и отправьте его боту. Бот копирует сообщение зарегистрированным пользователям с паузой 0,05 секунды между отправками и сообщает число доставок, недоступных личных чатов и других ошибок. `/cancel` сбрасывает текущий ввод в админ-панели.
- `/refund <user_id> <telegram_payment_charge_id>` возвращает Stars через Telegram. Команда предназначена для тестирования. Подписка и реферальный баланс остаются прежними, а статистика показывает валовую сумму зачисленных оплат. При необходимости отзовите доступ через админ-панель.

## Хранение и фоновые задачи

- `main.py` загружает конфигурацию, инициализирует SQLite и запускает polling Telegram и фоновую проверку подписок.
- `bot/database.py` создаёт таблицы `users`, `payments` и `invites`. Зачисление платежа, продление подписки и начисление бонуса выполняются в одной транзакции SQLite.
- `bot/handlers/` содержит обработчики меню, платежей, вступления и админ-панели. Кнопки определены в `bot/keyboards.py`, состояния ввода администратора — в `bot/states.py`.
- `bot/services/cryptobot.py` обращается к API основной или тестовой сети по настройке `CRYPTOBOT_TESTNET`.
- `bot/services/scheduler.py` проверяет сроки с паузой 60 секунд между проходами. Для активной срочной подписки с остатком до 24 часов бот один раз пытается отправить напоминание с кнопкой продления. По истечении он отзывает действующие ссылки пользователя, исключает его из канала, снимает блокировку, очищает срок в БД и пытается отправить уведомление. При ошибке исключения он записывает её в журнал и повторяет операцию в следующем проходе. Воркер также удаляет из БД записи о просроченных ссылках.
